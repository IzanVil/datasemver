Static site for DataSemver.

Source of truth is the main branch; this branch only holds the built page.
Regenerate by editing here directly, or see CONTRIBUTING on main.

`demo/` is the dashboard frontend from main with one addition, `replay.js`, which answers its
API calls from comparisons recorded against the real backend (`demo/data/`), so the page needs
no server. `fonts/` holds Outfit and DM Mono with their SIL Open Font License texts.
