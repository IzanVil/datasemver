Which version does this change deserve?

Compare two versions of a dataset. Read the bump they earn, the changes behind it and the changelog entry that explains it.

What the bump means

  • major

    Something consumers rely on is gone or means something else: a column removed, a type that no longer fits.

  • minor

    There is more than before and nothing that was there has moved: a column added, more rows.

  • patch

    The same meaning with better data: fewer gaps, a statistic that drifted a little.
